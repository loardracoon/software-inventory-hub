# Build order (Dictionary Hub)

One phase at a time. A phase is done when the build and tests pass and the app runs; tick it here and note follow-ups under it.

Prerequisites (local build, decided Oct 27, 2026): Docker and Node 22+; a Claude API key for Jev (H3); a Resend key for admin email (H2).

- [x] **Phase H0** — app shell and admin access → `hub-H0-shell.md`
- [x] **Phase H1** — schema and taxonomy seed (plan first) → `hub-H1-database.md`
- [x] **Phase H2** — client API as Edge Functions → `hub-H2-client-api.md` (the client's Phase 7 depends on it)
- [x] **Phase H3** — Jev, manual and automatic (plan first) → `hub-H3-jev.md`
- [x] **Phase H4** — editing, publishing and reclassification requests → `hub-H4-editing-publishing.md`
- [x] **Phase H5** — engines, usage, estimated cost and research engine → `hub-H5-engines-usage.md`

H3 calls the `ai_gateway` module that H5 completes: build a minimal gateway (mode check and `ai_calls` logging) in H3 and extend it in H5.

The `client-*.md` files describe the client app; they are here so this repo knows how the API is consumed (`client-07-hub-dictionary.md`).
